# 01. 渲染、路由和页面生成策略

网站页面怎么生成，会影响 SEO、性能、成本、实时性和开发复杂度。

## 常见渲染策略

静态页面：

```text
构建时生成 HTML
适合营销页、文档、变化少的内容
性能好，成本低
实时性差
```

服务端渲染：

```text
请求时读取数据并生成 HTML
适合动态内容、个性化页面、需要 SEO 的实时页面
```

客户端渲染：

```text
浏览器加载 JS 后请求数据
适合后台、交互型工具、登录后应用
SEO 较弱
```

增量生成或缓存渲染：

```text
兼顾静态性能和动态更新
适合大量内容详情页
```

## 页面类型和策略

营销首页：

```text
静态或缓存优先
```

内容详情页：

```text
需要 SEO，通常服务端或静态生成
```

后台管理：

```text
通常不需要 SEO，可以客户端或服务端混合
```

工具结果页：

```text
如果结果公开分享，需要服务端可访问
如果只是登录后使用，客户端渲染也可以
```

电商商品页：

```text
SEO 和性能重要，通常服务端/静态缓存
价格库存可能需要动态片段
```

## 路由设计

稳定 URL 很重要。

内容：

```text
/articles/:slug
/archive/:date
/tags/:tag
```

电商：

```text
/products/:slug
/cart
/checkout
/orders/:id
```

SaaS：

```text
/app/:workspaceId/projects/:id
/settings/billing
```

URL 应该表达资源和入口，不要暴露无意义实现细节。

## 常见坑

第一，内容页只客户端渲染，搜索引擎难收录。

第二，动态数据过度静态化，用户看到旧状态。

第三，URL 频繁变化，外链失效。

第四，后台和前台路由混在一起，权限复杂。

## 决策清单

- 页面是否需要 SEO？
- 数据变化频率如何？
- 是否需要个性化？
- 是否可以缓存？
- 页面是否需要登录？
- URL 是否稳定？
- 是否有分享入口？
