# 10. SEO、社交分享和增长入口

网站不是做好功能就会有人来。增长入口会反过来影响架构设计。

## SEO 模式

适合：

- 内容站
- 商品站
- 文档站
- 工具站落地页
- 本地服务站

关键要素：

```text
稳定 URL
唯一标题
Meta description
H1
结构化内容
内链
站点地图
robots
canonical
页面加载性能
```

SEO 的前提是页面能被搜索引擎访问和理解。

## 分享预览

社交分享需要：

```text
Open Graph title
Open Graph description
Open Graph image
Twitter card
公开可访问的图片 URL
稳定落地页
```

如果分享图需要外部平台抓取，它不能放在私有存储，也不能要求登录。

## 增长入口

常见入口：

```text
搜索引擎
社交分享
邮件订阅
邀请
广告投放
第三方平台
内容聚合
```

不同入口决定架构重点。

搜索入口需要详情页和索引。  
社交入口需要分享图和落地页。  
邮件入口需要订阅和发送系统。  
邀请入口需要归因和奖励。  
广告入口需要转化页和埋点。

## 内容沉淀

内容站最重要的是让每条内容变成可长期访问的资产。

这意味着：

```text
每条内容有独立 URL
归档页能发现历史内容
分类和标签形成内链
页面元数据唯一
旧内容不会轻易失效
```

## 数据分析

增长需要测量：

```text
访问来源
分享点击
搜索关键词
订阅转化
注册转化
付费转化
热门页面
跳出率
```

早期可以简单埋点，不必一开始做复杂 BI。

## 常见坑

第一，所有内容都堆在首页。

第二，详情页 URL 不稳定。

第三，分享图打不开。

第四，所有页面标题一样。

第五，不知道用户从哪里来。

## 决策清单

- 网站主要增长入口是什么？
- 核心内容是否有独立 URL？
- 是否需要站点地图？
- 分享图是否公开可访问？
- 分享落地页是否清楚？
- 是否需要邮件订阅？
- 是否需要邀请归因？
- 是否有基础统计？

## 练习

选择一个内容网站，分析它的增长路径：

- 搜索流量来自哪些页面？
- 社交分享落到哪里？
- 是否有订阅入口？
- 是否有可复用的内容归档？
