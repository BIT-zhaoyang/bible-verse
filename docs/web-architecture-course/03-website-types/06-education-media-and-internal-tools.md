# 06. 教育、媒体和内部后台

这一章把三类常见网站放在一起：教育网站、媒体网站和内部后台。它们看起来不同，但都强调资源生命周期和运营管理。

## 教育网站

核心资源：

```text
Course
Module
Lesson
Enrollment
Progress
Quiz
Assignment
Certificate
Payment
```

核心流程：

```text
购买/报名 -> 学习课程 -> 记录进度 -> 测验/作业 -> 完课 -> 证书
```

MVP：

```text
课程目录
课时详情
学习进度
购买或报名
```

成熟能力：

- 视频播放
- 测验
- 作业
- 证书
- 学员管理
- 班级
- 直播
- 社群

## 媒体网站

核心资源：

```text
MediaAsset
Episode
Playlist
Creator
PlaybackHistory
Favorite
Subscription
TranscodeJob
```

核心流程：

```text
上传 -> 转码 -> 存储/CDN -> 播放 -> 收藏/推荐 -> 订阅/广告
```

媒体网站重点是文件处理和播放体验。视频和音频通常需要异步转码、多清晰度、封面、字幕和 CDN。

## 内部后台

核心资源：

```text
业务对象
管理员
权限
操作日志
配置
任务
报表
```

核心流程：

```text
管理员登录 -> 查询数据 -> 执行业务操作 -> 记录日志 -> 影响前台或业务流程
```

内部后台不是“随便做做”。它要高效、准确、可追踪。

后台常见功能：

- 搜索筛选
- 表格
- 详情抽屉
- 批量操作
- 状态变更
- 导入导出
- 操作日志
- 权限控制

## 常见坑

教育网站：只做视频列表，没有学习进度。  
媒体网站：只上传原文件，没有转码和 CDN。  
内部后台：没有权限和日志，误操作无法追踪。

## 练习

为一个“小型在线课程网站”设计：

- 课程资源
- 学习进度
- 付费解锁
- 后台课程管理
- 完课证书
