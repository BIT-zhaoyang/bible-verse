# 01. 内容型网站

内容型网站的核心是把内容变成可被发现、阅读、分享和长期沉淀的资产。

## 典型例子

- 博客
- 新闻站
- 教程站
- 灵修网站
- 菜谱站
- 评测站
- 文档站
- 付费专栏

## 核心资源

```text
ContentItem
Author
Category
Tag
MediaAsset
Publication
Subscriber
```

简单内容站可以只有文章。成熟内容站会把作者、分类、标签、媒体、发布记录、订阅者拆开。

## 核心流程

```text
内容创建 -> 编辑/审核 -> 发布 -> 展示 -> SEO 收录 -> 分享传播 -> 订阅召回
```

如果有 AI 生成：

```text
素材/Prompt -> AI 生成 -> 人工审核 -> 发布 -> 反馈
```

## 页面结构

公开侧：

```text
首页
内容详情页
列表页
分类页
标签页
归档页
搜索页
关于页
订阅页
```

后台侧：

```text
内容列表
编辑页
预览页
审核队列
发布日历
媒体库
SEO 设置
数据看板
```

## MVP

内容站最小闭环：

```text
发布内容 -> 用户阅读 -> 用户分享或搜索访问 -> 内容沉淀
```

MVP 通常需要：

- 首页
- 详情页
- 归档或列表页
- 基础后台或内容源
- SEO 标题和描述
- 分享预览

可以暂缓：

- 评论
- 收藏
- 高级搜索
- 推荐系统
- 多作者
- 复杂分类

## 成熟演进

成熟内容站会逐步增加：

- 内容排期
- 多作者权限
- 版本历史
- 搜索索引
- 邮件订阅
- 个性化推荐
- 广告位管理
- A/B 测试
- 内容数据分析

## 数据模型提示

内容本体和发布记录不一定是一回事。

例如每日内容网站：

```text
Verse 是内容资产
DailyPublication 是某天采用了哪条内容
```

新闻站也可能类似：

```text
Article 是文章
HomepagePlacement 是首页推荐位置
NewsletterIssue 是某期邮件
```

不要把“内容是什么”和“内容在哪里展示”混为一张表。

## 常见坑

第一，没有独立详情页，内容无法沉淀。

第二，SEO 字段太晚补。

第三，把内容编辑和发布混为一谈。

第四，首页推荐直接写死，后期运营困难。

第五，订阅入口只是表单，没有真实发送和退订流程。
