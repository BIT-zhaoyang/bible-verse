# 01. 架构拆解练习

这一章用于训练“看到网站就能拆”的能力。

## 练习方法

每个网站都按同一套模板拆：

```text
一句话定义：
网站类型：
角色：
核心资源：
核心行为：
状态流转：
公开页面：
后台页面：
异步流程：
外部服务：
增长路径：
商业闭环：
MVP 范围：
```

## 练习 1：个人博客

要求拆出：

- 作者和游客
- 文章、分类、标签
- 草稿和发布
- SEO
- 归档
- 订阅入口

进阶：加入多作者和审核。

## 练习 2：二维码生成器

要求拆出：

- 输入表单
- 生成结果
- 下载
- 历史记录
- 匿名和登录用户区别

进阶：加入批量生成和付费套餐。

## 练习 3：在线课程

要求拆出：

- 课程、章节、课时
- 学员报名
- 学习进度
- 付费解锁
- 作业或测验

进阶：加入证书和老师后台。

## 练习 4：二手交易平台

要求拆出：

- 买家、卖家、平台管理员
- 商品发布
- 搜索匹配
- 聊天或询价
- 支付或线下交易
- 举报和下架

进阶：加入平台担保交易。

## 练习 5：AI 简历生成器

要求拆出：

- 用户输入资料
- 模板
- 生成任务
- PDF 文件
- 下载
- 历史版本

进阶：加入付费高清导出。

## 检查标准

完成后检查：

- 是否找到了核心资源？
- 是否有状态流转？
- 是否区分公开页面和后台？
- 是否识别了异步任务？
- 是否说明了 MVP 闭环？
- 是否有未来扩展路线？
