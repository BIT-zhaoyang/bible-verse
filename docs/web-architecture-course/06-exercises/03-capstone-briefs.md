# 03. 综合架构题

这一章是综合练习。每题都可以当成一个小产品架构设计任务。

## 综合题 1：AI 图片分享社区

需求：

```text
用户可以输入 prompt 生成图片。
用户可以保存历史结果。
用户可以把满意的图片发布到公开社区。
其他用户可以点赞、收藏、评论。
生成次数按套餐限制。
公开图片需要审核。
```

请输出：

- 网站类型组合
- 用户角色
- 核心资源
- 状态机
- 页面结构
- 后台结构
- 支付和权益
- 文件存储
- 审核流程
- MVP 范围

## 综合题 2：本地家政服务 Marketplace

需求：

```text
服务者可以发布服务和可预约时间。
用户可以搜索服务并预约。
平台收取抽佣。
预约完成后双方评价。
发生争议时平台介入。
```

重点考虑：

- 双边用户
- 服务 listing
- 可预约时间
- 订单和支付
- 履约状态
- 评价
- 争议处理

## 综合题 3：付费课程网站

需求：

```text
老师创建课程。
学生购买课程后学习。
系统记录学习进度。
课程包含视频、作业和测验。
完成后生成证书。
```

重点考虑：

- 课程层级
- 视频文件处理
- 学习进度
- 付费权益
- 作业提交
- 证书生成

## 综合题 4：小团队项目管理 SaaS

需求：

```text
团队可以创建项目和任务。
成员可以被邀请加入工作区。
不同角色有不同权限。
任务有状态、负责人、截止日期。
Pro 套餐限制成员数和项目数。
```

重点考虑：

- workspace
- membership
- role
- project
- task
- audit log
- subscription
- entitlement

## 综合题 5：每日灵感内容站

需求：

```text
系统每天发布一句名言和一张配图。
配图由 AI 生成。
管理员审核后发布。
用户可以订阅邮件。
每条内容可以被搜索和分享。
```

这个题和 Bible Daily Verse 类似。请尝试独立设计，再对照案例。
