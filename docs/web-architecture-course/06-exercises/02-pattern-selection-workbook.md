# 02. 模式选择练习册

这章训练“一个问题对应多种解决方案”的判断能力。

## 题 1：上传头像

场景：

```text
用户上传头像，文件小于 5MB，需要公开展示。
```

可选方案：

- 服务器中转上传
- 浏览器直传对象存储
- 第三方头像服务

请判断 MVP 用哪种，成熟版用哪种，并说明原因。

## 题 2：上传 500MB 视频

场景：

```text
创作者上传课程视频，需要转码和播放。
```

要求考虑：

- 直传
- 分片上传
- 转码任务
- 进度状态
- CDN
- 私有播放权限

## 题 3：文章搜索

场景 A：

```text
网站只有 100 篇文章，只需要按标题搜索。
```

场景 B：

```text
网站有 10 万篇文章，需要正文搜索、高亮和排序。
```

分别选择数据库搜索、全文索引或搜索引擎。

## 题 4：邮件订阅

场景：

```text
用户订阅每日内容推送。
```

要求设计：

- 订阅表
- 确认订阅
- 退订
- 发送日志
- 定时任务
- 失败重试

## 题 5：支付成功

场景：

```text
用户购买 Pro 套餐后获得每月 1000 次生成额度。
```

请说明为什么不能只依赖前端成功页，并设计 Webhook、订阅和权益判断。

## 题 6：AI 生成结果审核

场景：

```text
系统生成图片后，有时文字错误，必须人工审核后公开。
```

要求设计：

- 生成任务状态
- 审核页面
- 拒绝原因
- 重新生成
- 已批准结果发布
